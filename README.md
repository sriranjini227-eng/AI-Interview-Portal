# 🤖 AI Interview Portal

An AI-powered interview preparation platform that generates role-based interview questions, evaluates candidate responses, and provides personalized feedback using Google Gemini AI.

## 🚀 Live Demo

Frontend: https://ai-interview-portal-rho.vercel.app

Backend: https://ai-interview-portal-2zlf.onrender.com

---

## 📌 Features

- 🔐 User Authentication (JWT)
- 🤖 AI-generated interview questions
- 🎤 Speech Recognition for voice-based answers
- 📝 AI evaluation with score and detailed feedback
- 📊 Dashboard with interview statistics
- 📂 Interview history and detailed reports
- 📄 Download interview report as PDF
- ☁️ Cloud database using MongoDB Atlas
- 🌐 Fully deployed on Vercel and Render

## ⚙️ Installation

### Clone the repository

```bash
git clone https://github.com/sriranjini227-eng/AI-Interview-Portal.git
```

### Backend

```bash
cd backend
npm install
npm start
```

### Frontend

```bash
cd frontend
npm install
npm run dev
```

---

## 🔑 Environment Variables

Create a `.env` file inside the backend folder.

```env
PORT=5000
MONGO_URI=your_mongodb_connection
JWT_SECRET=your_secret_key
GEMINI_API_KEY=your_gemini_api_key
```
